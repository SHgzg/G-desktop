# 客户端框架设计文档

## 🏗️ 整体架构

基于 shadcn/ui 2024 最新版本的现代化客户端框架，集成侧边栏、顶栏和面包屑导航。

## 🎨 设计原则

### 1. 模块化设计
- **组件独立**：每个布局组件可以独立使用
- **状态管理**：使用 React Context 进行状态共享
- **类型安全**：完整的 TypeScript 类型定义
- **响应式优先**：移动端优先的设计理念

### 2. shadcn/ui 集成
- **最新版本**：基于 shadcn/ui 2024 最新 API
- **主题支持**：支持深色/浅色模式切换
- **无障碍**：遵循 WCAG 2.1 AA 标准
- **动画流畅**：使用 Framer Motion 增强动画

### 3. 布局特性
- **可折叠侧边栏**：支持展开/收起状态
- **响应式断点**：
  - 移动端：隐藏侧边栏，顶栏显示菜单按钮
  - 平板端：可折叠侧边栏
  - 桌面端：固定侧边栏
- **面包屑导航**：动态显示当前路径
- **顶栏操作**：搜索、通知、用户菜单

## 📱 响应式设计策略

### 断点定义
```css
/* 移动端 */
@media (max-width: 768px) { ... }

/* 平板端 */
@media (min-width: 769px) and (max-width: 1024px) { ... }

/* 桌面端 */
@media (min-width: 1025px) { ... }
```

### 适配策略
- **移动端 (< 768px)**：
  - 侧边栏隐藏，通过汉堡菜单访问
  - 顶栏简化，显示核心功能
  - 垂直堆叠布局

- **平板端 (768px - 1024px)**：
  - 可折叠侧边栏（默认收起）
  - 顶栏完整功能
  - 侧边栏覆盖模式

- **桌面端 (> 1024px)**：
  - 固定侧边栏（默认展开）
  - 完整布局体验
  - 可调整宽度

## 🎯 核心功能

### 1. 侧边栏功能
- **多级导航**：支持无限层级嵌套
- **搜索过滤**：实时搜索导航项
- **收藏夹**：快速访问常用页面
- **历史记录**：最近访问的页面
- **主题切换**：深色/浅色模式
- **用户偏好**：记住用户的展开/收起状态

### 2. 顶栏功能
- **全局搜索**：应用内全文搜索
- **通知中心**：显示未读消息和提醒
- **用户菜单**：用户设置、退出等操作
- **面包屑**：显示当前页面路径
- **视图控制**：全屏、布局切换等

### 3. 面包屑导航
- **自动生成**：基于当前路由自动生成
- **可点击**：支持快速跳转到父级页面
- **省略显示**：路径过长时智能省略
- **图标支持**：每个层级支持图标

## 🛠️ 技术实现

### 1. 状态管理
```typescript
// 导航状态
interface NavigationState {
  sidebarCollapsed: boolean
  activeItem: string | null
  breadcrumbs: BreadcrumbItem[]
  searchQuery: string
}

// 布局状态
interface LayoutState {
  screenSize: 'mobile' | 'tablet' | 'desktop'
  sidebarWidth: number
  headerHeight: number
}
```

### 2. 组件 API 设计
```typescript
// 主布局组件
interface AppLayoutProps {
  children: React.ReactNode
  sidebar?: React.ReactNode
  header?: React.ReactNode
  showBreadcrumb?: boolean
  className?: string
}

// 侧边栏组件
interface SidebarProps {
  collapsed?: boolean
  onCollapseChange?: (collapsed: boolean) => void
  navigation: NavigationItem[]
  className?: string
}
```

### 3. 性能优化
- **虚拟滚动**：大量导航项时启用
- **懒加载**：按需加载导航内容
- **防抖搜索**：搜索输入防抖处理
- **记忆化**：缓存计算结果
